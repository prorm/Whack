# Existing system audit

24 November 2026. Baseline captured before Moonshot changes.

| Area | Reuse | Gap to test |
| --- | --- | --- |
| React PWA | Hash routes, service worker, Rich/Lite/Offline delivery, accessible controls, IndexedDB media | Capture, citation and versioning workflow for one authored mission |
| Learning engine | Curated competency graph, diagnostic, event replay, recall scheduling, cached Remotion scenes | Map inventory error evidence to revision and avoid separate learner records |
| Proof and sync | Deterministic payout grading, local journal, same-origin SQLite sync, trainer receipts and consent | Add an inventory-specific rubric. Existing local preview and device tokens do not establish identity or employer readiness |
| Vertex lab | ADC, regional/global routing, model registry and historical ledgers | Prior caps and default output paths must stay isolated. Metadata discovery and inference success are distinct |
| Media | Existing 20-second reel, 19.52-second payout showcase, Sheru footage, app stills and SFX | A provenance-led inventory clip and comparisons. Creative quality and willingness to watch need learner input |

The baseline engine suite passed all 35 tests. The prior browser sprint reported 20 scanned screen states, 161 kB cold Lite and 296 kB cold Rich, and an offline payout submission synchronized after server restart. Device-native capture, Android performance, fluency, identity, paid placement and learning gains were unproven. A threshold policy and fixed manifests are preferable to extra runtime AI and a bandit with sparse observations.

The historic reports used Gemini 3.8 Flash, 3.5 Flash-Lite, 3.1 Flash-Lite, 3.1 Flash-Lite Image, Veo 3.1 Lite/Fast and Gemini TTS in different runs. Imagen 4 Fast returned 404 in the prior project trial. Historic pricing is usage-estimated and contains assumptions. Use the Moonshot atlas and ledger for current rates and fresh evidence.

The workspace root has no Git metadata. The nested Remotion repository contains existing uncommitted work, so this extension keeps the workspace structure and leaves its branch and prior assets untouched.
