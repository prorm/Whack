# ScrollProof X · Moonshot decision

**CONDITIONAL GO for the Experience Compiler.** Start with vocational educators and inventory leads who repeatedly teach how to reconcile stock. The first product turns one contributor's correction into an inspectable, versioned lesson. A learner can replay the reason, practice with unfamiliar numbers, and choose whether a reviewer sees the result.

## Product decision

| Question | Answer |
| --- | --- |
| 1 · Biggest problem | Practical know-how disappears when experienced people stop explaining it. Beginners also need evidence that they can apply it independently. |
| 2 · First users | Inventory leads and vocational educators teaching safe, repeatable spreadsheet work, with adults learning their first operations job. |
| 3 · Strongest innovation | A cited ExperienceTrace becomes a versioned playbook, practice and evidence record. Correct a disputed step beside the video before it reaches a learner. |
| 4 · Existing strengths | Deterministic calculation, competency graph, persisted learning events, cached reel composition, offline pack, rubric grading and consent-controlled evidence. |
| 5 · New capabilities exercised | Native video and stills produced structured draft traces. Audio input transcribed synthetic narration. Two model routes preserved eight protected terms in mixed text. Image generation, reference editing and both Kannada synthesis routes returned media. |
| 6 · Best model fit | 3.5 Flash-Lite for first-pass reasoning and cheap narrated drafts. 3.8 Flash LOW for this clip's missing fact. 3.1 Flash-Lite is a viable second audio path. 3.1 Flash-Lite Image is the cheaper visual candidate. Use explicit Kannada voice selection for TTS. |
| 7 · Overlap | Gemini Notebook on source-grounded formats, Scribe/Tango/Guidde/Dozuki on real workflow capture, Workera and Forage on practical scenarios, and Skill India on multilingual learning and opportunity discovery. |
| 8 · Proposed differentiation | The exact approved source version links a real action, its explanation and an unseen rubric. That link survives media switching and offline practice. Its market value is a pilot hypothesis. |
| 9 · Source-grounded lesson | **CONDITIONAL GO.** On one synthetic case the strong model found 5/5 actions and 4/4 measured facts. A cached result feeds the demo; cited review and deterministic rules are required. |
| 10 · Review burden | Unmeasured. The economics models eight paid minutes per release. Measure active expert minutes, wrong row attributions, unsupported quotes and correction frequency. |
| 11 · Entertaining reel | **CONDITIONAL GO** for reuse. Three real comparisons and an interactive recall exist. Voluntary viewing, preference and retention need learners. |
| 12 · Multiple media and languages | **GO** for local reading, audio, visual, practice and replay sharing progress. **CONDITIONAL GO** for Kannada text/voice pending native review, code-mixed audio and broader speech validation. |
| 13 · Meaningful offline use | **GO** for the prototype. It survived server shutdown, completed an unseen calculation, saved a private recording and synced evidence after reconnect. Physical-device behavior is pending. |
| 14 · Credible assessment | **GO** for the two formula values. **NO-GO** for inferred method, identity, authorship, employment readiness or automatic credentials. |
| 15 · Opportunities | Use the source-derived rubric in training. A learner can preview reviewed inventory evidence locally. No real employers, listings, pay or employment decisions participated. |
| 16 · Measured cost | 22 fresh requests. $0.1642786 usage-priced on known responses and $0.13566 conservatively held for three responses with unknown charges. About $0.30 inclusive. $1.73 of maximum reservations held against admission. |
| 17 · Projected cost | About $1.61 per reviewed playbook and $1.00 for one fluent translated pack in the stated labor scenario. Optional evidence review adds $0.60. Human time dominates reuse costs. |
| 18 · Weak areas | Intermediate values and exact quotes, correct SKU association under occlusion, fluent localization, private-media cloud routing, copy detection, and real-device ergonomics. |
| 19 · Abandon now | Per-learner generated video, automatic occupational credentials, fake job listings, and an autonomous community publication loop. |
| 20 · Build next | Collect two consented inventory walkthroughs. Test expert correction time and unseen learner transfer while preserving source and identity boundaries. |
| 21 · Demo memory | Show C5 producing the wrong value. Correct it with the source visible. Then answer “Why C4 instead of C5?” and jump back to the moment. |
| 22 · Adoption evidence | Contributors save measurable time and retain control over attribution. Learners can practice after losing internet and can explain the rule on different stock figures. |
| 23 · Human pilot items | Expert time, fluency, trust, usability, willingness to contribute, delayed recall, transfer and employer appetite. No participants were enrolled in this run. |
| 24 · Discoveries | In this test, five labelled stills cost more than native video for both models. Native video on 3.8 recovered the missing intermediate while Lite dropped it. Scripted follow-up added useful uncertainties and a grounding error. TTS, capture and basic retrieval are integration work. |
| 25 · Architecture | Run bounded inference when a source is contributed. Verify and version a shared playbook. Use local rules for learning and assessment. Bind optional server review and sharing to one submitted worksheet. |

## Why the condition matters

The value proposition depends on review saving time and authentic traces improving transfer. One synthetic recording cannot establish either. Two concrete negative results shape the design. Source labels and correct totals did not guarantee correct row attribution. Stronger inference improved one captured fact yet took 13.92 s on one call versus 2.64 s for the inexpensive native route. That tradeoff favors selective escalation and a source-first review interface.

Physical Android, manual screen-reader testing, real code-mixed speech, fluent Kannada review, a learner pilot and real expert participation remain pending. Fresh Veo/Omni generation was held because operation-level quota or entitlement was unresolved. Endpoint security on the test machine observed a synthetic form marker. The app sent zero capture POSTs and a real pilot requires an approved browser environment. Public moderation, cross-device recovery, job integration and identity verification remain staged.
